#Project Name: fit-app
#Short description
A responsive fitness workout platform where users can explore exercises, view workout details, save their favorite workouts,
and create a personalized daily workout plan. Users can also sort workouts by duration, calories, and rating.
#Technologies used
Next.js

React

TypeScript

Tailwind CSS

DaisyUI

React Context API

REST API

React Toast

JavaScript/ES6
#Features of the project
Workout Library – Browse and explore different fitness exercises with details like muscle groups, duration, calories, equipment, and rating.

Workout Details – View detailed information about each exercise and easily add it to your plan or saved list.

Personalized Workout Plan – Create and manage a daily workout plan with total exercises, minutes, and calories.

Save & Manage Workouts – Save favorite exercises and remove them whenever needed.
